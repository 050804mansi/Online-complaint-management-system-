# Rent Insights

A fresh Flask implementation of a house-rent estimator, with city/locality selection, an ML rent estimate, city/BHK listing ranges, BHK comparison chart, rent-per-square-foot context, and an embedded map search. The interface uses a gradient hero, coverage stats, a guided form, and a richer results dashboard.

## Protecting the project files
